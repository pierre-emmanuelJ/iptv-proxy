# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good faith, and keep discussions about
the project. Harassment, insults and personal attacks are not accepted.

Report abuse with GitHub's **Report content** option on the comment, or
mention the maintainer (@pierre-emmanuelJ) to step in. The maintainer may
remove comments or block accounts that break these rules.
